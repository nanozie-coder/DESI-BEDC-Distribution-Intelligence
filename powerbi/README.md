# Power BI report availability

The live four-page DESI Power BI Desktop (`.pbix`) report is **not included** in this public portfolio repository.

The dashboard modules are:

- **FCI** — Feeder Coverage Intelligence
- **SBTI** — Service Band Transition Intelligence
- **EDI** — Executive Decision Intelligence
- **FECI** — Feeder Energy Cap Intelligence

Selected corrected images can be uploaded from the prepared portfolio package. The pre-reconciliation screenshots are **not** suitable for public display.

Before sharing a PBIX, inspect its imported data, local server/instance identifiers, credentials, query paths, report metadata, bookmarks and public-source redistribution rights.
