## Why not publish older full-page screenshots?

Some earlier screenshots were captured **before source reconciliation or the final layout corrections** and contain misleading additional business units, newly observed feeder counts or obsolete chart panels. They are excluded.

## Upload procedure

Use GitHub's **Add file → Upload files** to upload the image files into a `screenshots` directory. Upload the four individual PNG files, not the ZIP archive.

Once the images are confirmed in the repository, embed them in the main README gallery with accurate captions. For truly complete four-page images, export each report page again from the final PBIX and replace any excerpt only after the KPI values are verified.

No passwords, personal correspondence, confidential BEDC information, database backups or executive pilot documents should be published.
